This project is the backbone for the automating dashboard upload process by taking the secondary media file and performing transformation and calculations so it is in the format used to upload into the dashboard as well. This will be used to make the streamlit app used by the team giving them all access to use it.

The different pages represent the different processes namely Social Media, Online Press, Social Media Videos and Broadcast exposure

Further improvements to be made are as follows; Multi-file handling to upload batch files for example for events with multiple days of exposure and Login authentication so only people with GSIQ email addresses will be able to access the site giving at least a small sembalnce of security.
